# 🚚 Last Mile Delivery Analysis | SQL Project

## 📌 Project Overview

This project focuses on analyzing last-mile delivery operations using SQL.

The objective of the project is to analyze delivery performance, customer and order patterns, driver and vehicle performance, delivery zones, and delivery problems to generate meaningful business insights.

## 🎯 Project Objectives

- Analyze delivery performance based on delivery status, duration, distance, and delivery attempts.
- Evaluate driver and vehicle performance.
- Identify high-performing and problematic delivery zones.
- Understand customer and order patterns.
- Generate actionable insights to improve delivery efficiency and reduce delays.

## 🗄️ Database Structure

The project contains five interrelated tables:

1. Customers
2. Orders
3. Drivers
4. Vehicles
5. Deliveries

The tables are connected using Primary Keys and Foreign Keys to maintain relationships between the data.
